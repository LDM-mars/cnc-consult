# CNC 미술학원 상담 프로그램

`Creative & Communication` 디자인 이미지를 그대로 화면으로 쓰는 상담 프로그램입니다.
학원 PC에서 실행하고, 같은 Wi-Fi에 있는 태블릿이나 폰 브라우저로도 접속할 수 있습니다.

## 실행하기

**필요한 것:** Python 3.8 이상. 추가로 설치할 패키지는 없습니다.

| 컴퓨터 | 실행 방법 |
|---|---|
| Windows | `run.bat`을 더블클릭합니다. Python이 없으면 python.org에서 설치하고, 설치할 때 "Add to PATH"에 체크하세요. |
| Mac / Linux | 터미널에서 `./run.sh`를 실행합니다. |

실행하면 브라우저가 열리고, 창에 접속 주소가 표시됩니다.

```
  이 컴퓨터에서:   http://localhost:8000
  태블릿/폰에서:   http://192.168.0.12:8000   (같은 Wi-Fi)
```

- 처음 접속하면 **학원 비밀번호**를 정합니다. 같은 Wi-Fi의 다른 사람이 상담 기록을 보지 못하게 막아 줍니다.
- 태블릿은 **가로 방향**으로 쓰세요. 화면 비율(16:9)이 그대로 유지됩니다.
- 실행 창을 닫으면 프로그램이 꺼집니다. 꺼져 있어도 데이터는 남아 있습니다.
- 다른 포트를 쓰려면 `run.bat --port 9000`처럼 실행합니다.

## 화면 흐름

```
시작(1.main) ─누르기→ 목차(2.목차) ─반 선택→ 반별 상담(3.각반별상담)
                                              ├ 신입생 → 반 소개 → 상담카드 4단계 (학생 정보 → 입시 정보 → 상담 결과·수강료 → 동의·서명)
                                              └ 재학생 → 반 학생 목록 → 학생 화면 (상담 기록 · 작품 · 성적 · 수강료 · 정보) → 학부모 리포트
```

- **왼쪽 위 ✕ 별**을 누르면 뒤로 갑니다. 키보드 `Esc`도 같습니다.
- **오른쪽 아래 ✦✦✦**을 누르면 관리 메뉴가 열립니다: 오늘 할 일 / 전체 학생 / 수강료 / 반 관리 / 입시 일정 / 설정.
- 이전·다음·저장 같은 주요 버튼은 화면 **아래쪽 왼쪽** 빈 곳에 있습니다.

## 처음에 할 일

1. **관리 → 반 관리**
   - 반마다 소개 문구, 커리큘럼, 수업 시간을 입력합니다. 지금 들어 있는 문구는 예시입니다.
   - **수강 옵션**도 추가합니다(예: 주3회 450,000원). 상담카드에서 수강료가 자동으로 계산됩니다.
   - **작품 예시 사진**을 올립니다. 사진이 없으면 목차의 원형 그림이 대신 나옵니다.
2. **재학생 → + 학생 추가**로 지금 다니는 학생을 넣습니다.
3. **관리 → 설정**에서 실기 종목과 작품 평가 항목을 학원에 맞게 고칩니다.

## 디자인 이미지 바꾸기

`design/` 폴더의 이미지를 **같은 이름의 새 파일**로 바꾸면 화면 디자인이 바뀝니다. 모두 1920×1080 PNG입니다.

| 파일 | 쓰이는 곳 |
|---|---|
| `1.main.png` | 시작 화면 |
| `2.목차베경.png` + `2-1~2-4버튼.png` | 목차. 버튼 이미지는 화면 전체 크기의 투명 PNG이고, 그림이 있는 부분만 눌립니다. |
| `3.배경.png` + `3-1, 3-2버튼.png` | 반별 상담(신입생/재학생). 다른 안쪽 화면과 학부모 리포트의 공통 배경으로도 쓰입니다. |
| `2.목차.png`, `3.각반별상담.png` | 완성본 참고용입니다. 프로그램에서는 쓰지 않습니다. |

버튼 위치가 달라졌거나 반 이름 글자 위치가 바뀌었다면 `app/static/js/screens.js`의 좌표만 고치면 됩니다.

## 백업

- **관리 → 설정 → 백업 내려받기**를 누르면 모든 데이터(학생 정보, 사진, 서명)를 zip으로 받습니다. USB나 클라우드에 정기적으로 보관하세요.
- 데이터는 `data/` 폴더에 있습니다(`app.db`와 `uploads/`).
- 복원하려면 프로그램을 끄고, zip을 풀어 나온 `app.db`와 `uploads/`를 `data/` 폴더에 덮어씁니다.
- `data/` 폴더에는 학생 개인정보가 들어 있으니 외부에 공유하지 마세요.

## 개발자용

```
app/server.py        표준 라이브러리 HTTP 서버 (정적 파일, /api/*, 로그인 쿠키)
app/api_*.py         API (반·학생·상담·작품·성적·리포트 / 수강료·일정·오늘 할 일 / 로그인·설정·업로드·백업)
app/db.py            SQLite 스키마와 초기값
app/static/js/stage.js    1920×1080 무대 스케일, 이미지 레이어, 알파(투명도) 클릭 판정
app/static/js/screens.js  디자인 파일 이름과 클릭 영역 좌표
app/static/js/pages/      화면별 코드
tests/test_api.py         API 테스트: python3 -m pytest tests/ -q
```
